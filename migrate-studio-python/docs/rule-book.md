# Python Edition Rule Book

The Python edition is scoped to Windows to Linux migration. It ships two rule
sources:

- `rules/migration_rules.json`: the MC runtime rule pack used by the Findings
  tab and MC auto-fixes.
- `rules/Migrate_Studio_Rules.xlsx`: the editable workbook rule book used by
  the standard Rules tab and contextual fixers.

Rules in this edition are tested against synthetic `EXAMPLE001` fixtures. Add
new examples there when adding or changing a rule.
