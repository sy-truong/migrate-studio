# Validation

Migrate Studio is a developer tool. It is not validated software, and it makes
no Part 11 claims. `history.json` is an operational log: the operator name comes
from Profile, which the operator can edit, so it is not an attributable audit
trail.

The rule books shipped in this repository are worked examples, and each
edition's rules are scoped to one migration direction. Any rule applied to
submission-bound code should be qualified under your own SOPs, with paired
before/after programs as evidence.

Before regulated use, qualify the exact edition, rule book, runtime version,
browser, and deployment mode. Keep the evidence outside this repository unless
it has been explicitly cleared for publication.
